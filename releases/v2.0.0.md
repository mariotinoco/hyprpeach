# a collection of Omarchy plugins, added one at a time

hyprpeach is now a small collection of Omarchy plugins for a desk with more than one monitor, installed as one plugin through Omarchy's own plugin manager. Installing it adds nothing to your bar; you choose what goes there.

**Install**

    omarchy plugin add https://github.com/mariotinoco/hyprpeach --enable
    ~/.config/omarchy/plugins/hyprpeach/bin/hyprpeach plugin add desktops

**What's in it**

- **desktops**: multi-monitor desktops that turn together across every screen, with the bar strip and the on-screen number. Same keymap, same behaviour as 1.x.
- **dev-ports** (new): an anchor on the bar that grows a red dot while a dev server is listening, grouped by the repository and branch it runs from.

Add or remove any of them with `hyprpeach plugin add <name>` and `hyprpeach plugin remove <name>`; `hyprpeach plugin list` shows what you have. They all update together with `omarchy plugin update`.

**Upgrading from 1.x**

    hyprpeach upgrade
    hyprpeach plugin add dev-ports

Your desktops, keys and monitors carry over. Afterwards, `~/.config/hypr/hyprpeach` is no longer used and can be deleted.

**Breaking**

- hyprpeach now installs to `~/.config/omarchy/plugins/hyprpeach` and loads the library from there.
- `install.sh` is deprecated. It still works as the bridge from 1.x, and nothing new goes into it.

To stay on one release, see "Pinning a release" in the README.
