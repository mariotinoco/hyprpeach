# SUPER + TAB opens the overview

`SUPER + TAB` now opens the overview on every monitor, when the overview plugin is added. Without it the key does nothing, as before. Set `toggle_overview = false` in `keys` to leave it unbound, or name another chord.

Monitors side by side at the same height are ordered left to right when desktops is added, so which screen holds which desktops no longer depends on the order Hyprland lists them.
