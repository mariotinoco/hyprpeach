# a number key closes it

Pressing `SUPER + 2` while the overview is open now closes it and takes you to desktop 2, rather than switching the desk underneath an overview that stays open. Any switch does the same — a number key, a click on the bar's strip, a cell.

A screen held with `SUPER + Y` is marked `held` on the desktop it is holding, as it was before 0.2.0.
