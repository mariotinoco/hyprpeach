# pin: SUPER + P to take a window with you

**New plugin: pin.** `SUPER + P` pins the window you are in — tiled or floating — and it follows you from desktop to desktop, on the panel it is on. Press it again to unpin. Together with Omarchy's `SUPER + T` to float, it replaces `SUPER + O`, which floats, resizes, centres and pins all in one press: two keys for two things.

    hyprpeach upgrade
    hyprpeach plugin add pin

A pinned window has a peach border, so you can see which ones will follow you.

`SUPER + P` was Omarchy's pseudo window; `hyprpeach plugin remove pin` gives both keys back.

**Fixed:** JetBrains Toolbox, which puts its window beside its tray icon every time it is shown, no longer puts it off the left edge of the screen when the bar is on the left: it opens just right of the bar, beside the tray. Any other floating window that opens entirely off every monitor is centred.
