# hyprpeach upgrade, and pinned windows that stay pinned

### `hyprpeach upgrade`

One word to move to the newest release. It re-runs that release's own installer, so upgrading and installing are the same path rather than two that drift apart. `hyprpeach version` says what is installed and what is available.

### A pinned window stays on the panel you pinned it to

Pin a floating window, switch desktops, and it would flip to the other monitor — seemingly at random, in either direction. Hyprland re-records a pinned window's workspace as the *focused* monitor's on every focus, which is wrong whenever those two differ; the next switch of that other panel then drags the window onto it.

Measured on a two-panel desk: one flip in ninety switches before, none in 272 after.

### The installer survives being run twice

It has to, now that it is also the upgrade path. It was appending a duplicate config block on every run, aborting on a re-tagged release, and leaving the bar strip on whatever version it was first installed at.
