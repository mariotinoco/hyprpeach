# upgrade cleanly from an early install

Two ways a machine installed before v1.1.0 could not reach the current release on its own.

**The bar strip would never have updated.** `omarchy plugin update` is a fast-forward, so it refuses a plugin clone whose history no longer descends from the remote's. It said so and returned non-zero, and the installer swallowed it — the library would upgrade around a bar strip frozen on the old widget. The failure is now caught and the strip reinstalled.

**Duplicate config blocks.** Installers before v1.1.0 could not match their own marker, so each run appended another `setup()` block to `hyprland.lua`. The installer now keeps the first and drops the rest, converging on one however many it finds.

Upgrading from any earlier version is one command:

```bash
curl -fsSL https://raw.githubusercontent.com/mariotinoco/hyprpeach/v1.1.2/install.sh | bash
```
