# nine desktops, a 3 × 3, and a living scene behind them

**The desk is now a 3 × 3.** Nine desktops, and `SUPER + 0` opens the overview — the whole grid at once — just as `SUPER + TAB` does. Desktop 10 is gone, and the number is fixed rather than a setting, because the overview and the new animated desktops are both built on that grid. The overview now shows the grid on every monitor, in that monitor's shape.

**New plugin: animated-desktops.** A real-time scene behind your desktops — a synthwave grid or a nebula — with a different place in it for every desktop, one picture across all your monitors composed around the one at eye level, and every desktop switch a flight to the next. `hyprpeach scene` switches between them.

    hyprpeach upgrade
    hyprpeach plugin add animated-desktops

animated-desktops builds a small renderer from source, so it needs Rust (`mise use -g rust@latest`); the first add takes a few minutes.

**Fixed:** with one screen held, moving the mouse between monitors no longer flashes a desktop number.

**Upgrading:** your windows stay where they are — every workspace keeps its number. Anything on desktop 10 is no longer on a desktop; move it off first, or gather it afterwards with `hyprctl eval 'require("hyprpeach").gather_rogue_windows()'`. If your own Hyprland config calls `setup()` with `desktop_count`, remove it: 3.0 refuses it rather than ignoring it.
