# a vertical bar, and a padlock instead of a number when held

### A held panel now looks held

`SUPER + Y` holds the panel under your pointer where it is while the rest of the desk keeps moving. This release makes that state legible instead of merely true.

- **The held tile becomes a padlock.** It stops being a number, and every other desktop on that strip goes quiet — they are not places that screen can go until you let it go.
- **Holding and releasing flash on the screen it happened to**, a padlock closing or opening, the same way changing desktop flashes a number. No notification: the flash is the message, and a toast on top of it is the same news twice in the corner of a different monitor.
- **The big number no longer flashes on a held screen.** It did not move, so it has no news.

### The bar goes vertical

The installer now runs `omarchy bar position left`. The desktop strip is a column of ten cells; on a horizontal bar they spend width competing with the clock and the tray, and a desk this model is for is wide.

This is the one thing the installer sets that is a preference rather than a consequence. `omarchy bar position top` — or `bottom`, or `right` — puts it back, and nothing in hyprpeach will argue.

### Upgrading

```bash
hyprpeach upgrade
```

Or, from an install that predates the command:

```bash
curl -fsSL https://raw.githubusercontent.com/mariotinoco/hyprpeach/v1.3.0/install.sh | bash
```
