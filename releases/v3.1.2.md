# the overview shows your scene again after upgrading

Upgrading from 3.0 left Omarchy's shell running the plugins it had already loaded — so the overview went on running 3.0's code, and showed your theme's wallpaper in its cells where the animated scene should be. An upgrade now restarts the shell once when it is behind: the bar blinks, and every plugin runs the new release.

    hyprpeach upgrade

If the overview is showing the wallpaper now, this fixes it; so does `omarchy restart shell`, or logging out and in.
