# shorter names, and the plugin list shows what needs what

Two plugins have shorter names: **dev-ports is now ports**, and **animated-desktops is now animated**. If you have either, `hyprpeach upgrade` carries it over by itself — same place on the bar, same settings, same scene and speed. There is nothing to re-add.

`hyprpeach plugin list` is now a tree, each plugin under the one it needs:

    🍑 desktops                 3.0.1    added      Multi-Monitor Desktops
    ├─ 🍑 animated              0.1.0    added      Animated Desktops
    └─ 🍑 overview              0.2.1    added      Desktop Overview
    🍑 ports                    0.1.0    added      Local Ports

Adding them fresh is now `hyprpeach plugin add ports` and `hyprpeach plugin add animated` — and a script that still says `dev-ports` or `animated-desktops` keeps working, with a note of the new name.

**Fixed:**
- `SUPER + 5` while already on desktop 5 no longer plays the start of a flight that goes nowhere.
- `SUPER + 2` with the overview open closes it and takes you to 2, with no number flashed over it.
- A held screen is marked `held` in the overview again.

**animated no longer needs you to install Rust.** It builds with the Rust its own `mise.toml` pins, which mise — part of every Omarchy install — fetches the first time.
