# your dev servers on the bar

An anchor on the Omarchy bar that grows a red dot while a dev server is listening. Click it for one port per line, grouped by the git repository, worktree and branch each process runs from, in your theme's colours. Stop one with a confirmation that names its pid.

Only dev ports: yours, from a git checkout, on a port somebody chose. System services, applications and ephemeral ports are left out.

    hyprpeach plugin add dev-ports
